# 🦙 Llamanac

A bubbly, Windows XP–inspired desktop almanac for Windows: a **calendar**, **sticky lists**, **goals** and **reminders** that stay where you put them. *(Formerly "Llama Calendars".)*

## ⬇️ Download

**[Get the latest version →](https://github.com/Llama-Engineer/llamanac-releases/releases/latest)**

Under **Assets**, download **`Llamanac-Setup-x.x.x.exe`** (the newest number) and run it.
You can ignore the other files; they're used by automatic updates.

## Installing

1. Run `Llamanac-Setup-x.x.x.exe`.
2. Windows may say **"Windows protected your PC"**, because the app isn't code-signed yet. Click **More info → Run anyway**.
3. Click through the installer. Llamanac opens, and a llama appears by the clock.

After that, **Llamanac updates itself.** New versions download quietly, and it asks before restarting.

## Good to know

- Everything you add stays **on your own PC**; nothing is uploaded anywhere.
- This repo only holds the installers. The **"Source code (zip)"** links GitHub adds to each release contain just this README.
